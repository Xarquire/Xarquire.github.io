# Emirhan Çelik · Portfolyo

**Canlı site:** https://xarquire.github.io

Rick and Morty'den esinlenen, boyutlar arası portal temalı kişisel portfolyo. Site açılırken bir portal tabancası şarj oluyor ve sizi siteye ışınlıyor.

- **Projeler** boyutlar arası kablo TV'de yayında
- **Yetenekler** garaj laboratuvarındaki şişelerde
- **İletişim** Bay Meeseeks kutusunda
- Üç boyut (tema), Schwifty modu ve keşfedilecek gizli rozetler

Tek bir HTML dosyası; kütüphane ya da derleme adımı yok. Görseller SVG ve Canvas ile çizildi, sesler tarayıcıda Web Audio ile üretiliyor.

## İçeriği güncellemek

Bütün içerik `index.html` içindeki `CONFIG` nesnesinden geliyor: isim, yetenekler, projeler, deneyimler ve bağlantılar. Değiştirip kaydetmek yeterli.

## Yerelde çalıştırmak

`index.html` dosyasını tarayıcıda açın.
