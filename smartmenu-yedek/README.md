# SmartMenuOS yedek site tasarımı

Canlı siteden (smartmenu/) ayrı, alternatif tasarım. Canlıya bağlı değildir;
Worker yalnızca `smartmenu/` klasörünü yayınlar, bu dal main'e de birleşmedi.

- Tasarım: Hallmark (github.com/Nutlope/hallmark) kuralları, "Newsprint" teması
  (gazete kâğıdı zemin, Zilla Slab başlık, Spectral metin, kiremit vurgu).
- İçerik: smartmenuos.com'daki bilgilerle aynı; yeni iddia, rakam ya da yorum eklenmedi.
- Görseller: smartmenu/img ve smartmenu/marka'dan kopya (gerçek uygulama ekranları).
- `noindex` açık; yayına alınırsa kaldırılmalı.
